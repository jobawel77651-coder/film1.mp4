# আমার সিনেমা: GitHub Pages-এ চালু করার নিয়ম

## ফাইল
- `index.html`: পুরো সাইট
- `config.json`: সাইটের নাম ও ভিডিওর তালিকা
- `videos/`: আপনার ভিডিও ফাইল (নিজে বানাতে হবে)

## ধাপ
1. github.com-এ নতুন repository খুলুন (Public)।
2. **Add file → Upload files** দিয়ে `index.html` আর `config.json` তুলুন।
3. আবার **Add file → Upload files** দিয়ে ভিডিওগুলো তুলুন। ফাইলের নামের আগে `videos/` লিখে দিলে ফোল্ডার তৈরি হবে (যেমন `videos/film1.mp4`)। ব্রাউজার থেকে একটা ফাইল সর্বোচ্চ ২৫ MB।
4. **Settings → Pages → Branch: main → Save** করুন। কিছুক্ষণ পর লিংক পাবেন।

## নতুন ভিডিও যোগ করা
1. ভিডিও ফাইল GitHub-এর `videos` ফোল্ডারে তুলুন।
2. সাইটে ১৩৩২ কোড দিয়ে ঢুকুন, শিরোনাম আর পাথ (`videos/film1.mp4`) লিখে যোগ করুন।
3. **config.json ডাউনলোড** চেপে ফাইলটা GitHub-এর পুরোনো `config.json`-এর জায়গায় বসান।

কোড ১১২২৬৬ দিলে শুধু ভিডিও আর শিরোনাম দেখা যায়।

## সীমাবদ্ধতা
- কোড HTML-এ লেখা নেই, শুধু হ্যাশ আছে। তবে এটা ব্রাউজারে চলা সাধারণ গেট। ভিডিওর লিংক কেউ জেনে গেলে সরাসরি খুলতে পারবে, আর ছোট কোড অনুমান করা সহজ।
- ব্যাকএন্ড নেই বলে সবার জন্য আপলোড GitHub-এ ফাইল তুলে করতে হয়। ফোনে বেছে নেওয়া ভিডিও শুধু ওই ফোনেই থাকে।
